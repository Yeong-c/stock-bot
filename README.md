# 아빠 주식 알림봇 (dad-stock-bot)

아버지가 전화로 불러주신 검색식 6종을 **텔레그램 봇**으로 만든 프로그램입니다.
윈도우 데스크톱에 켜두면, 아버지는 핸드폰 텔레그램으로 신호만 받고 매매는 직접 하십니다.

- 장중(09:00~15:30): **1번 분봉 거래폭발**을 1분마다 감시 → 터지면 즉시 알림
- 장 마감 후(15:45): **2~6번 검색식**을 전 종목에 돌려서 결과 발송
- 아침(08:30): 감시 준비 완료 인사 (봇이 살아있다는 확인용)
- 버튼으로 감시 종목 추가/삭제, 결과 다시 보기, 지금 검색 가능

> 봇은 신호만 보냅니다. 주문 기능은 일부러 넣지 않았습니다.

## 1. 검색식 정의 (통화 내용 → 규칙)

| # | 이름 | 조건 | 발송 |
|---|------|------|------|
| 1 | **분봉 거래폭발** | 감시 종목의 **1분 거래량**이 평소의 **6배 이상**. 평소 = 최대 1년치 1분봉 거래량을 큰 순으로 정렬해 **상위 60% 평균** (2차 요청으로 3배·중간40% → 6배·상위60%) | 장중 즉시 (같은 종목 10분 간격) |
| 2 | **바닥 매집** | 고점이 **2년 이상 전**이고 고점 대비 **60% 이상 하락** + **월봉 2달 연속 양봉** (진행 중인 이번 달 포함) | 장 마감 후 |
| 3 | **급락 수급** | **30일 내 고점 대비 50% 이상 하락** + 당일 거래량이 **최근 3일 평균의 2.5배 이상** | 장 마감 후 |
| 4 | **급등 눌림** | **20일 내 27% 이상 급등**했던 종목이 **고점 대비 30% 이상** 눌림 | 장 마감 후 |
| 5 | **정배열 돌파** | 20 > 60 > 120 > 240일선 **정배열** + 거래량 **3일 평균의 3배** + **양봉 +4% ~ +15%** | 장 마감 후 |
| 5-b | **정배열 깊은눌림** | 정배열 유지 중 **120일 고점 대비 30% 이상** 하락 (통화 끝에 덧붙이신 "고점 대비 30% 내려온 종목 중 정배열"을 이렇게 해석) | 장 마감 후 |
| 6 | **일봉 거래폭발** | 1번과 같은 방식, **3년치 일봉** 기준. 당일 거래량이 상위 60% 평균의 **6배 이상** | 장 마감 후 |

**공통 필터**: 시가총액 1,000억 미만 · 투자주의환기종목(KIND) · 관리종목(KIND) · 정리매매=상장폐지 결정 종목(KIND, 최근 3개월) · 투자위험종목(네이버) · 거래정지(당일 거래량 0) · 우선주 · 스팩 · 코넥스 제외.
투자주의/경고/과열은 **제외하지 않습니다** (직접 거르심). 각 목록은 수집 실패 시 마지막 성공본을 씁니다.

**반복 필터**: 같은 검색식에 최근 20일(`output.repeat_days`) 안에 이미 떴던 종목은 "이전에 뜬 종목"으로 접어 뒤에 붙이고, **새로 뜬 종목**을 먼저 보여줍니다 (`data/results/날짜.json` 이력으로 판단).

**겹침 종목**: 검색식 2개 이상에 같이 걸린 종목을 검색식 수 + 상위권 가산 점수로 정렬 (텔레그램 🔗 겹침 종목, 데스크톱 '겹침' 버튼). 아버지가 말씀한 정량 점수 부분입니다. AI 정성 점수는 비용 문제로 뺐습니다.

**오늘 시황**: 나스닥·다우·S&P500·코스피·코스닥, 달러/원·달러인덱스·WTI·금, 네이버 주요뉴스 제목 10개를 무료로 수집해 아침 08:30 메시지에 붙이고 📰 버튼/데스크톱 탭에서도 봅니다. AI 요약은 없습니다.

해석이 들어간 부분(아버지께 한 번 확인하면 좋은 것):
- 2번 "고점"은 최근 5년 데이터 안의 최고가. "2년 이상 하락"은 그 고점이 2년 이상 전이라는 뜻으로 처리.
- 4번 "+27%"는 20일 창 안의 최저가(고점 이전) → 최고가 상승률.
- 5-b는 별도 검색식으로 분리. 필요 없으면 `config.yaml` 에서 `aligned_pullback.enabled: false`.
- 1번 기준값은 **키움 REST API 연결 시 최대 1년치**, 미연결 시 네이버가 주는 **최근 7거래일치**로 계산 (메시지에 어느 쪽인지 표시됨).
- 장 시작 후 5분은 시초가 거래 폭주라 1번 알림 제외 (`ignore_first_minutes`).

모든 숫자는 **`screeners.yaml`** 에 있습니다. 이 파일은 `/update` 로 함께 내려가므로 규칙을 바꾸면 푸시만 하면 아버지 PC 에도 적용됩니다. `config.yaml` 은 토큰·키·감시종목 같은 개인 설정 전용이고, 거기 남은 옛 규칙은 무시됩니다(`override_rules: true` 를 넣으면 개인 규칙 우선).

## 2. 설치 (아버지 윈도우 PC, 처음 한 번)

1. **Python 3.12 설치** — https://www.python.org/downloads/ → 설치 첫 화면에서 **"Add python.exe to PATH" 체크** 후 Install.
2. 이 폴더(`dad-stock-bot`)를 통째로 PC에 복사 (예: `C:\dad-stock-bot`). `.venv`, `data`, `logs` 폴더는 복사 안 해도 됨.
3. `install.bat` 더블클릭 → 라이브러리 설치 (2~3분).
4. **텔레그램 봇 만들기** (핸드폰 또는 PC 텔레그램)
   - `@BotFather` 검색 → `/newbot` → 이름 입력 (예: `아빠주식알림`) → 아이디 입력 (예: `appa_stock_bot`, 끝이 `bot`)
   - 나오는 **토큰**(`1234567890:AAF...` 형태)을 복사
5. `config.yaml` 을 메모장으로 열어 `bot_token: "여기에_봇_토큰_붙여넣기"` 에 토큰을 넣고 저장. `pair_code` 는 원하는 숫자로 바꿔도 됨.
6. `check.bat` 더블클릭 → 전부 OK 인지 확인.
7. `run.bat` 더블클릭 → 봇 시작. (검은 창이 떠 있어야 함. 닫으면 꺼짐)
8. 아버지 핸드폰 텔레그램에서 봇 아이디 검색 → **시작** → `pair_code` 숫자(기본 1234)를 보내면 연결 완료. 버튼 메뉴가 뜸.

### 바탕화면 아이콘 = 아버지용 데스크톱 프로그램 (권장)
큰 글씨 창 하나로 텔레그램과 같은 일을 다 할 수 있습니다: 홈(켜기/종료/업데이트, 오늘 알림) · 검색 결과(검색식별 보기, 지금 검색) · 감시 종목(추가/삭제) · 오늘 알림 · 설명.
**데이터 누적**: 일봉은 5년치를 캐시하고 매일 갱신, 분봉은 네이버 7거래일치를 날마다 파일에 누적해(`data/minute/코드.csv`) 시간이 지날수록 기준값이 길어집니다(최대 1년). 글씨 크기는 왼쪽 아래 버튼으로 조절.
맥에서 미리 보기(윈도우 봇과 충돌 없이 창만): `.venv/bin/python launcher.py --no-bot`

`install.bat` 이 끝나면 바탕화면에 **"아빠 주식 알림봇"** 아이콘이 생깁니다 (다시 만들려면 `make_desktop_icon.bat`).
- 더블클릭 → 작은 창이 뜨고 봇이 켜집니다. 큰 글씨로 **● 실행 중** 이 보이면 정상.
- **종료** 버튼 → 봇이 꺼집니다. 창의 X 를 눌러도 "끌까요?" 묻고 끕니다.
- 봇이 멈추면 15초 후 자동으로 다시 켭니다.
- 아이콘을 두 번 눌러도 봇은 하나만 뜹니다 (같은 PC 안 중복 실행 잠금). 이미 켜져 있으면 "이미 실행 중" 이라고 나옵니다.
- PC 켤 때 자동으로 이 창이 뜨게 하려면 `make_startup_icon.bat` 한 번 실행.

### 부팅 시 자동 실행 (창 없이, 고급)
`Win + R` → `shell:startup` 엔터 → 열리는 폴더에 `run_hidden.vbs` 의 **바로가기**를 넣으면 PC 켤 때 자동 실행됩니다.
그리고 **절전 모드 끄기**: 설정 → 시스템 → 전원 → 화면/절전 "안 함". (PC가 자면 봇도 잡니다.)

봇이 죽어도 `run.bat` 이 15초 후 자동으로 다시 띄웁니다.

## 2-b. 맥(macOS)에서 설치·실행 (형이 미리 테스트할 때)

파이썬 코드는 윈도우와 똑같고, 실행 스크립트만 `.command`(더블클릭) 로 준비돼 있습니다.

1. `python3 --version` 이 3.10 이상이면 그대로, 없으면 https://www.python.org/downloads/macos/ 에서 설치.
2. `install.command` 더블클릭 (또는 터미널에서 `./install.command`). 처음이면 "확인되지 않은 개발자" 경고가 뜰 수 있음 → 파일 우클릭 → **열기**.
3. `config.yaml` 에 봇 토큰 입력 → `check.command` 로 점검 → `run.command` 로 실행 (터미널 창 닫으면 종료, 죽으면 15초 후 자동 재시작).
4. 검색식만 돌려보려면 `scan.command`.

로그인 시 자동 실행(창 없이, 죽으면 자동 재시작):
```bash
bash mac/autostart_install.sh    # 등록 (launchd LaunchAgent)
bash mac/autostart_remove.sh     # 해제
```
자동 실행 중 로그는 `logs/bot.log`, `logs/launchd.err.log`. 맥도 절전에 들어가면 알림이 끊기니 시스템 설정 → 배터리/에너지 에서 잠자기 방지.

터미널로 직접 할 때:
```bash
cd dad-stock-bot && source .venv/bin/activate
python -m stockbot check
python -m stockbot scan
python -m stockbot           # 봇 실행
```

## 2-c. 원격 업데이트 (아버지 PC를 직접 만지지 않고 새 버전 배포)

코드를 GitHub **공개 저장소**에 올려두면, 아버지 PC 가 거기서 새 버전을 받아옵니다. 비밀은 `config.yaml` 에만 있고 저장소에는 올라가지 않습니다(.gitignore).

**형이 할 일 (한 번)**
1. GitHub 에 `dad-stock-bot` 저장소 생성 (Public).
2. 이 폴더에서 푸시:
   ```bash
   git remote add origin https://github.com/<깃허브아이디>/dad-stock-bot.git
   git push -u origin main
   ```
3. 아버지 PC 의 `config.yaml` 에 `update.repo: "<깃허브아이디>/dad-stock-bot"` 한 줄 입력 (처음 한 번만 원격으로).

**새 버전을 낼 때마다**
1. 코드 수정 → `VERSION` 숫자 올리기 (예 1.1.0 → 1.1.1) → `CHANGELOG.md` 맨 위에 항목 추가.
2. `git commit -am "..." && git push`
3. 아버지 PC 에서 둘 중 하나:
   - 실행 창의 **업데이트** 버튼 (새 버전이 있으면 창에 파란 글씨로 미리 알려줌, 6시간마다 확인)
   - 형이 텔레그램에서 **`/update`** 전송 → 봇이 스스로 받아서 다시 켜짐. `/version` 으로 확인.

업데이트 시 `config.yaml`, `data/`(감시종목·연결정보), `logs/`, `.venv/` 는 건드리지 않고, 이전 파일은 `backup/` 에 3세대까지 보관됩니다. `requirements.txt` 가 바뀌면 라이브러리도 자동 설치합니다.

## 3. 키움 REST API 연결 (선택, 1번 기준값을 1년치로)

없어도 모든 기능이 돌아갑니다. 연결하면 1번 분봉 기준값이 7일치 → 최대 1년치로 좋아집니다.

1. https://openapi.kiwoom.com 접속 → 키움 ID로 로그인 → **API 사용신청** (REST API) → **앱키 / 시크릿키** 발급
2. `config.yaml` 의 `kiwoom.app_key`, `kiwoom.app_secret` 에 입력, `is_mock: false`
3. `check.bat` 로 "키움 API: OK" 확인
4. 감시 종목 1개당 1년치 1분봉 수집에 **1~3분** 걸림 (키움 제한: 초당 1회). 처음 한 번만 오래 걸리고 이후는 증분.

> 로그인 비밀번호는 프로그램에 절대 넣지 않습니다. 앱키/시크릿키만 사용합니다.

## 4. 텔레그램 버튼 사용법 (아버지용 → `아빠_사용법.md` 참고)

| 버튼 | 하는 일 |
|------|---------|
| 📋 오늘 검색결과 | 저장된 결과를 검색식별 버튼(종목 수 표시)으로 골라 봄. '전체 한 번에'도 있음 |
| 🔥 감시종목 | 1번 분봉 감시 중인 종목과 기준값 |
| ➕ 감시 추가 | 종목 이름을 보내면 감시에 추가 (예: `삼성전자`). "삼성전자 추가" 라고 바로 보내도 됨 |
| ➖ 감시 삭제 | 종목 이름 또는 번호 (예: `2`) |
| 🔎 지금 검색 | 검색식을 하나 골라 즉시 실행. 10분 안의 결과는 재사용, 아니면 1~3분 |
| 🔗 겹침 종목 | 여러 검색식에 같이 걸린 종목 |
| 📰 오늘 시황 | 미국 지수·환율·유가·주요뉴스 제목 |
| (명령) /update, /version | 새 버전 받기 / 버전 확인 (2-c 참고) |
| ❓ 도움말 | 검색식 설명 |

명령어: `/status` (봇 상태·다음 작업 시각), `/scan`, `/id`, `/help`

## 6. 점검·수동 실행

```bash
python -m stockbot check          # 설정·네트워크·키움 점검
python -m stockbot scan           # 검색식 2~6 즉시 실행, 화면 출력 (scan.bat)
python -m stockbot baseline 005930   # 분봉 기준값 생성 테스트
python -m stockbot universe       # 유니버스 통계
```

문제가 생기면 `logs/bot.log` 를 보면 됩니다. 봇이 오류를 만나면 텔레그램으로도 하루 한 번 알려줍니다.

## 7. 데이터 출처와 한계

- 일봉/실시간/분봉(7일): 네이버 금융 공개 API. 약 1분 지연 가능.
- 상장목록·시가총액: FinanceDataReader(KRX). 환기종목: KIND(kind.krx.co.kr).
- 1분봉 1년치: 키움 REST API(선택).
- 실시간 감시는 **1분 간격 폴링**이므로 초 단위 즉시성은 없습니다 (아버지 요청이 1분봉 기준이라 충분).
- 임시 휴장일은 `config.yaml`의 `holidays` 에 추가 (주말은 자동).
